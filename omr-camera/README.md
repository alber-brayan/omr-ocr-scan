# Lectora OMR (Android)

App de captura para **OMR OCR SCAN**. Fotografía fichas por salón y curso y exporta un ZIP para calificar en la app web.

## Compilar

1. Abre esta carpeta en Android Studio.
2. Copia `local.properties.example` a `local.properties` y define `sdk.dir`.
3. Ejecuta en un dispositivo o emulador.

El APK de cada versión se publica en GitHub Releases, no dentro del repositorio.
